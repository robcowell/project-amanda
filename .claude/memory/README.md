# Portable notes

Copies of the Claude Code memory files from the machine these were written on.
They normally live in `~/.claude/projects/<path-derived-name>/memory/`, which is
per-machine *and* named after the project's absolute path — so they do not
follow the repo to another machine on their own.

Kept here so they do. To use them on a new machine, copy the `.md` files (not
this README) into that machine's own memory directory for this project.

`CLAUDE.md` at the repo root is the durable version of this knowledge and is
read automatically; these are the working notes behind it.
